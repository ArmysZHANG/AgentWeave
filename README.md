## 二、个人研发项目：TaskWeave

**TaskWeave** 是我正在持续开发的个人 AI Agent 应用平台，探索从传统 AI 聊天机器人向可执行任务的数字员工工作平台演进。

主要研究和开发方向包括：

- **AI Agent：** 智能体配置、模型接入、工具调用与任务执行。
- **Skill / MCP：** AI 能力封装、统一管理与复用。
- **企业知识库：** 文档解析、RAG 检索、元数据管理与引用溯源。
- **材料写作工作台：** 参考材料、提纲生成、正文编辑与 AI 润色。
- **会议助手：** 语音转写、说话人识别、会议摘要与待办提取。
- **Workflow：** 业务流程编排与自动化执行。
- **Agentic UI：** 面向业务任务的交互式 AI 工作界面。

> TaskWeave 目前为个人持续研发项目。本仓库主要用于 AgentWeave 品牌介绍和技术实践索引，不代表 TaskWeave 核心代码已经开源。
